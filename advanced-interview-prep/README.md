## 笔记模板（四段式 + 专题）

1. **文章总结**：核心框架 + 工具箱/要点表格 + 补充知识（文章未提的加分点）+ 面试策略
2. **Q&A**：按面试问题组织，答案给推理链和演进史，不只背结论
3. **简历可用案例**：专业技能栏 + 项目经历（简洁版一行 + 口述版），⚠️ 数字要替换为真实场景
4. **面试官连环追问**：深挖题 + 防坑点 + 易混淆概念对比
5. **专题深挖（可选）**：讨论中展开的机制级内容（如大 key 八层危害、优雅下线时间轴）

## 使用方法

- **面试前**：按"简历案例 → 连环追问"路径复习，口述演练
- **日常**：按模块线性学习，笔记间的交叉引用是设计好的伏笔（如分布式锁 ↔ 缓存一致性、限流 ↔ atlas-rate-limit 实战）
- **实战联动**：笔记中标注了与公司真实系统（atlas-rate-limit、Dubbo/Sentinel 技术栈）的对照点
