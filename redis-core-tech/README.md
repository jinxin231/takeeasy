## 课程框架：两大维度 + 三大主线

- **两大维度**：系统维度（设计原理）+ 应用维度（场景/案例驱动）
- **三大主线**：
  - 高性能：线程模型、数据结构、持久化、网络框架
  - 高可靠：主从复制、哨兵机制
  - 高可扩展：数据分片、负载均衡
