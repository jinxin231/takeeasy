1. **主线**：01→02 建立概念 → 03~09 五模块原理 → 14~17 集群与一致性——这是 MQ 知识的骨架
2. **对比线**：10~13 与 23~26 对照读（四款 MQ 的基础与集群双视角）
3. **应用线**：27~35 功能篇按业务需求点读（顺序/幂等/延时是高频）
4. **视野线**：36~42 架构升级 + 43~44 演进与商业化——架构师视角
5. **配套**：与 `advanced-interview-prep/3.mq`（面试实战向）交叉阅读：原理在这里，话术在那边
