## 课程定位

与高阶面经（邓明，偏面试实战）不同，本课程是**消息队列原理课/分布式系统原理课**：从"设计一个最简单的 MQ"开始 → 扩展为集群 → 添加高级功能 → 云原生/Serverless 架构升级。目标是成体系的知识结构，而不是面试话术。

**作者背景**：腾讯云消息队列团队，负责过多款 MQ 产品的商业化、内核优化、架构升级、大规模集群稳定性。

## 学习方法论（本课的核心主张）

1. **不用每款 MQ 都学一遍**：MQ 设计思想基本一致、演进中相互借鉴。从需求出发理解"设计原理 → 主流方案 → 方案优劣 → 选型思考点"，再学任何一款都事半功倍
2. **掌握关键路径 = 体系化知识结构**：选型问题（如"哪款 MQ 性能最高"）拆成因子——通信协议、网络模型、存储结构、生产消费原理、集群部署、分片副本——逐因子对比再映射到具体产品即可回答
3. **源码学习的正确姿势**：先看懂原理再看源码（知其然才知所以然）；进阶路径是去开源社区做 Contributor（作者本人参与了 Kafka/RocketMQ/Pulsar 社区）
4. **MQ 是串联计算机基础知识的主线**：分布式、网络编程、操作系统、存储原理、数据结构、一致性——学 MQ 等于复习整个计算机体系

## 课程结构（六个模块）

| 模块 | 内容 | 对应讲次 |
|---|---|---|
| 预习篇 | MQ 发展脉络、基础概念对齐 | 01~02 |
| 基础篇 | 最小 MQ 五要素：通信协议、网络模块、存储模块、生产者、消费者；拆解 4 款主流 MQ | 03~13 |
| 进阶篇 | 集群化七件事：瓶颈分析、集群构建、数据一致性、安全、可观测、编码技巧、集群优化；再拆 4 款 MQ | 14~26 |
| 功能篇 | 顺序、幂等、延时、事务、死信、优先级、消息查询、Schema、WebSocket | 27~35 |
| 架构升级篇 | 存算分离、分层存储、Serverless/Event、容灾、数据集成、消息中台 | 36~42 |
| 经验总结篇 | 未来演进、商业化、研发经验、产品思维、运维运营 | 43~47 |

## 四个角色视角（读每篇时的代入点）

- **使用者**：选型（功能/性能/稳定性横向对比）
- **研发**：底层原理、设计思考、实现方案
- **运维**：架构风险点、长期运维成本、监控体系
- **架构师**：功能清单、架构优劣势、风险、成本结构、社区活跃度

> 笔记用法：本课程笔记以"原理拆解 + 设计权衡"为主线，Q&A 按"设计决策问答"组织，可与 `3.mq`（面经实战版）对照阅读——原理在这里，话术在那边。
